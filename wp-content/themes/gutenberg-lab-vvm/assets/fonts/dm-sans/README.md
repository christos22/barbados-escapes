# DM Sans webfonts

Self-hosted Latin variable webfonts from Google Fonts, downloaded 2026-09-09.
Normal and italic files support weights 100–1000. WordPress registers them in
`theme.json` for both the frontend and block editor; no Google Fonts request is
needed at runtime.

- Source family: https://github.com/google/fonts/tree/main/ofl/dmsans
- CSS: https://fonts.googleapis.com/css2?family=DM+Sans:ital,wght@0,100..1000;1,100..1000&display=swap
- Normal: https://fonts.gstatic.com/s/dmsans/v17/rP2Yp2ywxg089UriI5-g4vlH9VoD8Cmcqbu0-K4.woff2
- Italic: https://fonts.gstatic.com/s/dmsans/v17/rP2Wp2ywxg089UriCZaSExd86J3t9jz86MvyyKy58Q.woff2
- Licence: SIL Open Font License 1.1, included in `OFL.txt`.
