# Figtree webfonts

These webfont files come from the official Figtree repository, pinned to
[version 2.0.3](https://github.com/erikdkennedy/figtree/tree/v2.0.3/fonts/webfonts):

- `Figtree-Light.woff2` (300)
- `Figtree-Regular.woff2` (400)
- `Figtree-Medium.woff2` (500)
- `Figtree-Bold.woff2` (700)

Figtree is distributed under the SIL Open Font License 1.1. The upstream
license is included in this directory as `OFL.txt`.
