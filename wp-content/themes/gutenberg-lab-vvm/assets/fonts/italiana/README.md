# Italiana

This directory contains the Latin webfont subset of Italiana Regular (400).

- Upstream family: https://github.com/google/fonts/tree/main/ofl/italiana
- Webfont source: https://fonts.gstatic.com/s/italiana/v21/QldNNTtLsx4E__B0XQmWaXw.woff2
- License: SIL Open Font License 1.1; see `OFL.txt`
- WOFF2 SHA-256: `5079c87a4e86c58e8cd4f18ec2d3255918b7d565708ed934b15c4710301f838c`

The stable WordPress font preset slugs remain `display-serif` and
`site-primary` so existing block content continues to resolve its selected font.
